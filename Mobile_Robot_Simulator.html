Student task

  1. Move forward and observe the coordinates.
  2. Turn left or right and note the heading.
  3. Navigate around all obstacles.
  4. Try the auto demo, then pause or reset.
  5. Record whether the robot reaches the goal without touching an obstacle.

Learning check

1. What does the heading represent?

The direction the robot's front is facing, measured in degrees.

2. What does the trail show?

The path followed by the robot as it moves.

3. How can obstacle avoidance be added?

Use sensor distance and a rule to stop or turn when an obstacle is near.

4. Is this a full physics simulator?

No. It is a lightweight 2D kinematic teaching app.

Runs locally in a modern browser. No installation, account, internet connection, or data upload required.
